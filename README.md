# Windows 12 Concept

A fan-made Windows 12 style desktop that runs entirely in the browser. Plain HTML, CSS and JS, no build step.
Not affiliated with or endorsed by Microsoft.

## Deploy on Vercel
- CLI: `npm i -g vercel`, then `vercel --prod` inside this folder.
- Dashboard: push to GitHub, import the repo, Framework Preset "Other", leave build/output empty.

## What's inside
Boot + lock screen, floating taskbar, Start menu with search, quick settings, notification/calendar panel,
snap-to-edge windows, desktop right-click menu, a real file system saved in localStorage.
Apps: File Explorer, Notepad, Terminal, Calculator, Nova Browser, Settings, Aura assistant.
